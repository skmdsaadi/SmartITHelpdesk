# Recorded Phase 3 evaluation

These files were generated by `python -m app.train_classifier` from the bundled dataset and pinned dependencies. They record actual measured outputs, not target values.

- `report.json`: metrics, candidate validation thresholds, confusion matrices, limits and runtime versions.
- `split_manifest.json`: complete example/group membership; no group crosses partitions.
- `test_predictions.csv`: every held-out positive-class prediction, including mistakes and abstentions.
- `confusion_matrix.csv`: raw held-out confusion counts, with the same label order as the UI.

All examples are synthetic. In particular, the 36/36 accepted positive-class predictions do not imply perfect accuracy: four positive-class raw predictions were wrong and one of twelve unrelated test controls was incorrectly accepted. See the model card for context.

To reproduce on Windows, from the backend directory run:

```powershell
.\.venv\Scripts\python.exe -m app.train_classifier
```

The default output is the ignored `backend/evaluation/` directory. To deliberately replace these checked-in evidence files after a documented model change, use `--output ..\docs\evaluation`. Review the dataset and evaluation policy before accepting a different result. Python/platform versions may differ across environments; split IDs and confusion counts should be reproducible with the pinned numerical dependencies.
